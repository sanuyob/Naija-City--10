# Original downloaded sources — Fictional Lagos

These source archives are kept outside the web-served `public/` directory. The curated extracted GLBs live under `public/assets/fictional-lagos/library/`.

- `originals/kenney-commercial.zip` — Kenney City Kit (Commercial), CC0 1.0.
- `originals/kenney-suburban.zip` — Kenney City Kit (Suburban), CC0 1.0.
- `originals/kenney-roads.zip` — Kenney City Kit (Roads), CC0 1.0.
- `originals/kenney-industrial.zip` — Kenney City Kit (Industrial), CC0 1.0.
- `originals/kenney-nature.zip` — Kenney Nature Kit, CC0 1.0.
- `originals/innerscene__low-poly-nature-palm-tree.glb` — individual Innerscene source model, CC0 dedication.

Run `python3 scripts/build-fictional-lagos-library.py` from the repository root to regenerate the extracted catalog and district manifests. Source licenses are copied into `public/assets/fictional-lagos/licenses/`; the CSV asset register captures per-model origin, source URL, attribution, hash and verification state.
