# Project-authored Yaba street utility asset

`overhead-wire-span.glb` is generated from source by `scripts/generate-yaba-overhead-wire-span.mjs`. It contains three parallel sagging overhead service cables, each 12 m between endpoints, with a 0.52 m centre sag. It has roughly 1,176 triangles and no textures. It is intended to be instanced between utility pole tops after local alignment checks.
