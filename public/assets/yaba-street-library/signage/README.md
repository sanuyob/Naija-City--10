# Yaba sign texture pack

Eight original 1024×512 PNG sign-face textures for Nigerian street businesses. Created for Naija City using `scripts/generate-yaba-signage-textures.mjs`; they are not downloaded brand logos.

- `yaba-provisions.png`
- `mide-phone-repairs.png`
- `fresh-cut-barbers.png`
- `mama-ts-kitchen.png`
- `akara-and-pap.png`
- `suya-and-grill.png`
- `pos-and-transfers.png`
- `cold-drinks.png`

Use as sign-face textures on suitable mesh surfaces. Review UV orientation and material setup before use in game. Texture dimensions are 1024×512 each.
